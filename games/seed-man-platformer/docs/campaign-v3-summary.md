# Seed Man Campaign V3

This release expands Sprout Run from one level to an 11-level campaign.

## New levels

1. Greenhouse Gauntlet
2. Nursery Night Shift
3. Reservoir Run — The Phantom Pump
4. Root Zone Rumble
5. Mycelium Mile
6. Trichome Transit — Mite Queen
7. Kief Cavern Climb
8. Rosin Refinery Rush
9. Terpene Tunnel — Mildew Wraith
10. Frostline Canopy
11. Cloud Nine Citadel — Pollen Warden

## Campaign additions

- four themed worlds
- ten new settings
- nine traversal-mechanic families
- four stomp bosses with increasing hit counts
- per-level completion and best-time tracking
- level selector and Next Level flow
- campaign desktop/mobile Chromium acceptance
- live campaign browser verification

## Seed Man animation-v2

The locked Seed Man contract is preserved while motion readability is improved with idle breathing/blinking, run stride/lean, jump stretch, double-jump pose, landing squash, hurt face, boss-stomp recoil, finish pose, leaf follow-through and speed trails.

This document is descriptive only; `game.json`, the campaign/level data, generated-course tests and public runtime are the machine sources of truth.
