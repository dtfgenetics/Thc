# Seed Man Platformer

The **Seed Man Platformer** is an original browser-game project using DTF Genetics' Seed Man mascot as the player character.

## Character contract

The canonical mascot remains a short, chubby oval seed with a simple face, three-leaf sprout, rubber-hose limbs, white gloves/shoes, thick outline, and flat 2D treatment. Game animation may pose the character for movement while preserving the locked silhouette and identity.

## Prototype scope

- side-scrolling browser gameplay
- keyboard and touch controls
- run, jump, fall, land, collectible, damage, checkpoint, and finish states
- original cultivation/fantasy environments rather than copied platform-game worlds
- original enemies, hazards, level geometry, audio, UI, and progression

## Current status

`concept-to-prototype` — character direction is established; mechanics, level design, art sheets, physics constants, and campaign structure remain open.
