# High Life

**High Life: From Bagseed to Legacy** is an original cannabis-industry life-path board game in controlled preproduction.

This directory is the GitHub source-of-truth for machine-readable rules, component schemas, digital prototypes, validation, and implementation notes. Approved art, print masters, proofs, and release packages remain outside code storage until cleared for release.

## Locked structure

- Three historical/gameplay eras: **Underground → Medical → Legal**.
- Players progress through a branching career/grower path instead of a single circular property board.
- Core systems include reputation, assets, harvest/income, opportunity, risk, era events, and end-game legacy scoring.
- The visual identity, written rules, cards, economy, board geometry, terminology, and components must remain independently designed.

## Current status

`canonical-preproduction` — the game system is defined enough for implementation, but a complete playable browser build and final print package are not yet approved.

## Next implementation gate

Build a deterministic rules engine first, then a browser prototype, then print-layout exports. Do not lock economic values until simulated playtests show that no era or strategy dominates by default.
