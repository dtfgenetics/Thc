# Trichome Trials

Production target: **dtfseeds.com**

Trichome Trials is a deterministic judging/scorecard browser game. Each round presents a fictional entry with a compact evidence packet. The player scores seven categories from 1–10, submits the card, then compares their judgment with a hidden benchmark rubric.

## First playable vertical slice

- deterministic six-character trial codes;
- five judging rounds with no repeated entry in a run;
- seven locked categories: Structure, Resin, Terps, Yield, Color, Documentation, Problem Solving;
- fictional entries with evidence statements and hidden benchmark scores;
- 1–10 player scorecard for every category;
- accuracy score based on total absolute error plus an exact-category bonus;
- benchmark reveal with category-by-category explanations after submission;
- cumulative trial points, average accuracy, exact calls, and final judge rank;
- responsive keyboard/mobile-safe DOM controls and reduced-motion support;
- original CSS judge-table, sample-card, loupe, badge, and score-meter assets;
- canonical data/engine synchronized with the self-hosted public runtime.

## Content boundary

All entries and judging packets are fictional. The game teaches observation, documentation, and consistent rubric use. It does not provide potency claims, consumption guidance, chemical instructions, or step-by-step cultivation/processing procedures.

## Current status

`browser-vertical-slice`. Rules testing, browser/mobile playtesting, accessibility review, deployment registration, and production release remain separate gates.
