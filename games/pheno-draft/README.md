# Pheno Draft

Production target: **dtfseeds.com**

Pheno Draft is a deterministic roguelike genetics card game. Each run starts with a fictional founder line and a target profile. Across six rounds, the player chooses one parent from a three-card draft, reviews three generated phenotype cards, and keeps one line moving forward.

## First playable vertical slice

- deterministic six-character run codes;
- one founder card plus a deterministic target profile;
- six draft rounds with three parent choices per round;
- three deterministic phenotype cards generated from each selected cross;
- seven abstract traits: Vigor, Resin, Aroma, Color, Structure, Speed, and Stability;
- objective-fit scoring plus improvement bonuses;
- two limited draft refresh tokens per run;
- run archive showing the selected line at every round;
- final rank based on fit, score, and improvement;
- canonical/public engine and data parity;
- responsive keyboard/mobile-safe browser controls and reduced-motion support.

## Content boundary

All cards, line names, trait values, phenotype outcomes, and objectives are fictional game data. Pheno Draft does not provide real-world breeding probabilities, cultivation parameters, potency claims, chemical instructions, or step-by-step production guidance.

## Current status
