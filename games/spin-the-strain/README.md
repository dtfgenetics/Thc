# Spin the Strain

Production target: **dtfseeds.com**

Spin the Strain is a deterministic community wheel game. A six-character wheel code reproduces the same equal-weight spin sequence so players can share a challenge and compare results without hidden weighting.

## First playable vertical slice

- three modes: Strain Picker, Grow Challenge, Community Wildcard;
- 18 equal-weight entries per mode;
- deterministic six-character wheel codes;
- no immediate repeat when a mode has more than one entry;
- animated browser wheel with accessible result announcements;
- spin count and 12-result session history;
- direct challenge link sharing with mode + wheel code;
- responsive keyboard/mobile-safe DOM controls and reduced-motion handling;
- canonical data/engine synchronized with the self-hosted public runtime.

## Mode intent

- **Strain Picker** uses original fictional game cultivar names and makes no product or real-world cultivar claims.
- **Grow Challenge** supplies short educational/community prompts rather than scoring scientific correctness.
- **Community Wildcard** supplies event-night conversation and participation prompts; it does not represent gambling or prize fulfillment.
