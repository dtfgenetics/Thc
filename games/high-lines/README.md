# High Lines

Production target: **dtfseeds.com**

High Lines is an interactive cannabis-themed coloring and activity game built around original line-art scenes. The playfield stays large and central while a compact palette and activity rail provide fill, undo, reset, hidden-object, prompt, and sharing controls.

## First playable vertical slice

- four original interactive SVG scenes;
- deterministic six-character scene codes;
- each code selects a scene, creative prompt, and palette rotation;
- fillable SVG regions using an eight-color palette;
- keyboard-accessible regions and palette controls;
- undo last fill and reset artwork;
- three hidden-object bonuses per scene;
- completion/progress scoring from unique colored regions and found objects;
- creative activity prompt per run;
- shareable scene-code URL;
- responsive layout with a large unobstructed art board;
- reduced-motion support;
- canonical/public data, engine, and SVG asset parity.

## Art direction

The first scene set includes a neon grow room, a fantasy cloud garden, a trichome observatory, and a seed-city skyline. The artwork is original black-line SVG illustration designed specifically for this game. No downloaded third-party coloring pages are used.

## Content boundary

High Lines is a creative coloring/activity game. Its grow-room and plant imagery is illustrative; it does not provide real-world cultivation parameters, chemical instructions, equipment settings, potency claims, or consumption guidance.

## Current status

`browser-vertical-slice`. Rules testing, browser/mobile QA, accessibility review, deployment registration, and production release remain separate gates.
