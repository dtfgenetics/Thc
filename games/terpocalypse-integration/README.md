# Terpocalypse website integration

Canonical game source and design authority: `dtfgenetics/Terpocalapse`.

This directory tracks the DTFSeeds production integration for **Terpocalypse: Grow Room From Hell**. The first packaged release is **Level 01 — The Veg Lab**, based on the stable no-dependency browser FPS prototype in `dtfgenetics/Terpocalapse/prototypes/web-fps`.

## Production route

`/games/terpocalypse/`

## Current playable slice

- retro Canvas raycaster
- keyboard/mouse and touch controls
- Trim Shears, pH Blaster, Neem Cannon
- Spider Mite Swarm, Powdery Mildew Ghoul, Nute Burn Imp
- health, armor, ammo, keycard and special pickups
- locked containment door
- Trichome Burst special
- mission-complete and death states
- local best-score persistence

The browser package intentionally uses code-drawn placeholders until original art/audio passes the canonical Terpocalypse asset and rights gates. It does not include third-party shooter art, maps, audio, branding, or copied UI.
