# Dtf420 Atlas live verifier

Run with Node 22 or newer:

```bash
DTF_SITE_URL=https://dtfseeds.com node scripts/verify-dtf420-atlas-live.mjs
```

The script performs cache-busted, no-redirect public checks for the canonical `/learn/atlas/` surface, representative lessons from all 10 systems, the nested Three.js runtime, and preservation of the WordPress `/learn/` hub.
