Core rule

Leaves often show root problems.

Yellowing, curl, necrosis, slow growth, wilt, and deficiency-like symptoms can all be caused by root-zone issues. Root checks must come before aggressive nutrient corrections.

Diagnostic focus

Verify the hidden half.

Root-zone diagnostics should pair visual symptoms with substrate moisture, pH, EC, irrigation history, oxygen availability, media structure, temperature, and recent changes.
