Root-Zone Diagnostics

This page gives the repeatable root-zone diagnostic flow: observe leaf symptoms, check moisture and container behavior, verify pH and EC, inspect oxygen/aeration risk, then connect findings before correcting.

Leaf ModuleLeaf Field Card

Diagnostic sequence

  1. Document leaf symptom pattern and canopy location.
  2. Check container weight and substrate moisture.
  3. Review irrigation timing and dryback behavior.
  4. Measure pH and EC from the most useful available source.
  5. Inspect root appearance, smell, drainage, and aeration risk.
  6. Compare recent changes against symptom timing.
  7. Decide what to verify next before changing feed.
Rule: root-zone diagnosis prevents overcorrecting visible leaf symptoms.
