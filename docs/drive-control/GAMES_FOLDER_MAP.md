## Purpose

Google Drive `04 Games` is the canonical human-readable home for DTF / THC game specifications, approved art, print masters, playtest records, and release files. GitHub is canonical for code, machine-readable game data, tests, and build/deployment configuration.

## Standard folder pattern for new/lightly structured games

1. `00 Control`
2. `01 Rules`
3. `02 Board or Game Data`
4. `03 Art / Images`
5. `04 Cards / Components`
6. `05 Digital`
7. `06 Playtesting`
8. `07 Approved Release`
9. `99 Archive`

Do not dismantle mature existing project structures solely to match this template.

## Separation rules

- Keep High IQ trivia data separate from THC U Know and Strain Showdown.
- Keep Weedopolis board assets separate from High Land.
- Keep final print files out of draft-art folders.
- Do not merge project identities because an old repo/chat used a different name.
- Game renames must be reflected in the master tracker and source-of-truth docs.
