## Canonical top-level navigation

The shared header uses exactly: **Home, Seeds, Learn, Courses, Diagnostic, Games, Community, Shop**.

1. Home → `/`
2. Seeds → `/seeds/`
3. Learn → `/learn/`
4. Courses → `/courses/`
5. Diagnostic → `/tools/`
6. Games → `/games/`
7. Community → `/community/`
8. Shop → `/shop/`

Do not rename Seeds to Genetics, Diagnostic to Tools, or merge Courses into Learn. Gallery, About, Contact, Search, Account, and Cart stay outside the primary row.

## Responsive behavior

Desktop keeps the eight destinations in one row while they fit. Tablet collapses before crowding. Mobile keeps the DTF Genetics brand and utility access, shows all eight destinations in the same order when Menu opens, uses 14–16px page gutters, and keeps touch targets at least 44px. The shared Mobile Polish layer must load after the responsive-layout and UX-polish layers.

## Fidelity rule

The approved image remains the visual reference for dark evergreen palette, spacing rhythm, active-state treatment, and brand hierarchy. The eight-item row above is the information-architecture source of truth.
