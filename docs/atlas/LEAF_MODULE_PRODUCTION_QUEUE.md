## Page expansion template

Each lesson page should include:

- Plain-language definition
- Biological function
- What growers should observe
- What measurements matter
- Common misreads
- Diagnostic boundaries
- Required images
- Field-card/downloadable asset
- Related Atlas sections
- Related Grow Doc prompts

## Diagnostic language rule

Do not say a visible symptom proves a cause. Use language like:

- suggests
- may indicate
- narrows the possibilities
- should be checked with
- requires context from

Avoid language like:

- definitely means
- always caused by
- guaranteed deficiency
- visual proof
