# Plant Atlas Root Macro / Microscopy Source Review

Updated: 2026-09-23

## Goal

Fill the remaining `root-tip` production classes with defensible Cannabis-specific reference material:

- `macro-reference`
- `microscopy-reference`

The owned `labeled-botanical-plate` can be illustrative, but real macro/microscopy slots must remain empty until tissue identity, provenance, license and useful source resolution are established.

## Candidate A — Morales et al. 2026 / PLOS ONE + Zenodo root image dataset

Article:
- *Diversity of root system architecture and root-shoot biomass allocation in industrial hemp (Cannabis sativa L.)*
- DOI: 10.1371/journal.pone.0339929
- PLOS ONE
- Article license: Creative Commons Attribution (CC BY)

Associated dataset:
- Zenodo DOI: 10.5281/zenodo.17783092
- `2022_GH-15B_Hemp_RootCrownCamera_Images.zip` — root-crown camera images
- `2022_GH-15B_Hemp_RootFlatbedScanner_Images.zip` — roots scanned at 600 dpi
- metadata tables for RhizoVision processing

Status: **high-priority source candidate**

Why it is strong:
- Cannabis/hemp-specific.
- Modern controlled phenotyping study.
- Root crown and high-resolution flatbed datasets exist separately.
- Study describes root excavation and same-day imaging methods.
- Root images were used quantitatively rather than as decorative illustrations.

Required before registration:
1. Inspect the dataset license at the file/record level.
2. Select an individual image with clear genotype/sample metadata.
3. Confirm whether the chosen frame is suitable for a root-tip macro reference or only whole-root architecture.
4. Preserve the genotype/sample identifier in media provenance.
5. Do not present scanner imagery as microscopy.

Status: **background/reference source**

## Candidate C — Cannabis root anatomical studies

Recent Cannabis anatomy papers report transverse-root anatomy, including cortex, endodermis/pericycle, xylem, phloem and secondary development.

Status: **source-resolution/license review needed**

Rules:
- A root transverse section is not interchangeable with a root-tip/root-hair image.
- Do not register cross-section microscopy as `PA-RTIP-001` unless it actually depicts the intended young root-tip/absorbing region.
- ResearchGate-hosted figure previews are not used as production masters unless the underlying version-of-record license and original-resolution file are independently verified.
