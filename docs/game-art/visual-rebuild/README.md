# DTFSeeds Game Visual Rebuild — Portfolio Index

Status: ACTIVE
Updated: 2026-09-09

This directory is the production planning system for the visual rebuild of the DTFSeeds game portfolio. It converts the portfolio goal into game-specific art, UI, animation, responsive-layout, and runtime-asset requirements.

Read `MASTER_VISUAL_PRODUCTION_STANDARD.md` first. Every game brief inherits it.

## Portfolio goal

DTFSeeds games should look and feel like intentional browser games, not generic web pages containing game controls. Each title gets a distinct visual fantasy, a protected playfield, clear interaction hierarchy, original art, responsive composition, and production-ready assets.

The current product preference is to use **High Land** and **Weedopolis** as visual/reference anchors rather than wholesale-resetting their approved direction. Their briefs focus on responsive polish, compatibility, and reusable lessons unless the product direction is changed later.

## Approval sequence

For every title: visual brief → concept board → responsive gameplay mockups → asset manifest → approved source masters → normalized runtime exports → integration → phone/tablet/desktop QA → performance/accessibility review → release packaging.

Do not generate hundreds of final assets before the first concept board and responsive gameplay frame establish the correct visual language.
