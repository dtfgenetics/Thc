# THC Weekly Crossword — Visual Rebuild Brief

Route: `/games/crossword/`
Current owner: `dtfgenetics/Thc-crossword-`
Rebuild class: new premium puzzle UI over puzzle/content systems.

## Visual goal

A weekly cannabis cultivation crossword presented like a premium illustrated puzzle issue: clean grid first, clue notebook second, theme art around the edges.

## Required assets

- logo/weekly issue cover system.
- crisp vector/DOM crossword tile styling.
- numbered, selected, active-word, correct, incorrect and hint states.
- clue notebook/panel skin.
- pencil/cursor and completion/streak graphics.
- category/weekly decorative art.
- completion celebration and share card.

## Responsive composition

Phone portrait: grid dominates top, clue bar below, keyboard/input area bottom, clue list in drawer. Tablet portrait: grid + adjacent/under clue pane depending orientation. Desktop: grid left, clue notebook right, no oversized marketing header during play.

## First approval pack

One weekly issue identity plus phone/tablet/desktop puzzle screens and tile-state strip.
