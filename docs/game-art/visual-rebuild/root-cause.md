# Root Cause — Visual Rebuild Brief

Proposed/public integration path: `/games/root-cause/`
Current owner: `dtfgenetics/Thc`
Rebuild class: new diagnostic-deduction presentation over deterministic case/engine data.

## Visual goal

A cultivation investigation game where each case feels like inspecting a real grow-space scenario: symptoms, environmental context, inspections and differential diagnoses arranged as an evidence workflow rather than an educational form.

## Required assets

- logo/key art and investigation-table/grow-room scene.
- case-image/illustration frame system.
- symptom markers and environmental-context icons.
- inspection-tool family.
- four-diagnosis candidate-card system.
- confidence/progress/remaining-inspection indicators.
- correct diagnosis, wrong diagnosis, root-cause reveal and score effects.
- six-character case-code/share card.
- results/case-file archive treatment.

## Responsive composition

Phone portrait: case visual first, two inspection actions and diagnosis cards below/in sheet; never force four tiny side-by-side diagnoses. Tablet: case evidence left, diagnosis/inspection pane right. Desktop: large evidence board with current case central and compact differential rail.

## First approval pack

One complete case presentation, six symptom/context icons, inspection tools, diagnosis cards, reveal state and phone/tablet/desktop layouts.
