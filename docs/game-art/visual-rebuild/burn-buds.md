# Burn Buds — Visual Rebuild Brief

Route: `/games/protect-the-plants/`
Current owner: `dtfgenetics/Thc`
Rebuild class: new strategy-board presentation while retaining useful multiplayer/API/game-state systems.

## Visual goal

A cannabis garden fleet-battle strategy game played across a stylized 15×15 grow-grid battlefield. It should read instantly as tactical play, not a spreadsheet grid.

## Required assets

- logo/key art.
- master garden battlefield and opponent-board variant.
- five cannabis-themed formation designs with intact/damaged/burned states.
- target reticle, shot/hit/miss, fire/smoke/ember effects.
- placement ghosts, valid/invalid placement states.
- turn indicator, room/lobby, player banners, chat/reconnect and rematch treatment.
- victory garden and defeat/burnout scenes.

## Responsive composition

Phone portrait: one board at a time with clear My Garden/Opponent toggle; 15×15 cells must stay tappable via responsive board sizing/zoom strategy. Tablet landscape: two boards or board + fleet tray. Desktop: dual-board composition where space permits.

## First approval pack

Garden board, all five formation silhouettes, combat state strip, phone single-board and desktop dual-board screens.
