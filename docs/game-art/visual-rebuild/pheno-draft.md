# Pheno Draft — Visual Rebuild Brief

Route: `/games/pheno-draft/`
Current owner: `dtfgenetics/Thc`
Rebuild class: new breeding-table/card presentation over draft/selection logic.

## Visual goal

A breeder's selection table where parent cards, trait tradeoffs, keeper outcomes and lineage progression feel collectible and strategic.

## Required assets

- logo/key art and breeding-table background.
- 20 parent-card illustrations/treatments.
- phenotype result and keeper hero cards.
- trait icons, parent frames and lineage connectors.
- objectives/round-progress UI.
- refresh/reroll, select, reject and final-line effects.
- final lineage/results presentation.

## Responsive composition

Phone portrait: current choices shown as 2–3 large swipeable cards, objectives compact above, detail on tap. Tablet: choice row + trait inspector. Desktop: full breeding table with multiple cards visible and lineage/objectives to side.

## First approval pack

Six representative parent cards, trait icon sheet, breeding table, result card and phone/tablet/desktop draft screens.
