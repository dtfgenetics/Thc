# Strain Match — Visual Rebuild Brief

Route: `/games/strain-match/`
Current owner: `dtfgenetics/Thc`
Rebuild class: new memory-game presentation over simple matching logic/content.

## Visual goal

A tactile educational memory deck set in a stylized garden/seed-library environment. Pairs should be identifiable and rewarding without relying on tiny text.

## Required assets

- logo/key art and card back.
- illustrated pair-card family and educational reveal cards.
- garden/library board background.
- flip, match, mismatch, streak and completion effects.
- timer/move/streak symbols if used.
- themed deck/environment variants for later replay value.

## Responsive composition

Phone portrait: 4-column grid sized for confident tapping; matched-card details open below/in sheet. Tablet/desktop: larger grid with educational inspector at side. Card art must remain distinguishable at smallest runtime size.

## First approval pack

Eight representative pair fronts, card back, board, state strip and phone/tablet/desktop grids.
