# Archived GitHub Workflows

Files in this directory are preserved as historical operational evidence but are intentionally outside `.github/workflows/`, so GitHub Actions will not register or execute them.

## Retirement rule

A workflow is moved here only after its active trigger path has been superseded and the canonical replacement is documented.

### hostinger-game-route-repair.yml

- Former role: manual emergency direct-Hostinger game-route repair.
- Status at retirement: the workflow itself identified this path as a legacy emergency fallback.
- Canonical replacement: the WordPress V2 transactional public-suite publishing/repair path governed from `dtfgenetics/Thc`.
- Retirement action: preserved byte-for-byte outside the executable workflow directory.
