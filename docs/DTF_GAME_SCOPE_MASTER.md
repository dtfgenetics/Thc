## Current development direction

The portfolio may be redesigned, rewritten, migrated, restructured, consolidated, renamed, rerouted, or rebuilt in whatever order best advances the current game-quality goal. Existing source, mechanics, data, multiplayer, art, validation, and deployment systems are reusable material rather than mandatory implementation contracts.

Current ownership/status information is recorded in `data/project-registry.json`, visitor routes in `data/public-navigation.json`, deployment mappings in `site/deployment/public-apps.json`, and visual rebuild direction in `docs/game-art/visual-rebuild/`.

Keep those records synchronized with the implementation that actually exists as the redesign progresses.
