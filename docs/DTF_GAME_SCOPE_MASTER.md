## Missing outlined game slate

These previously outlined titles are part of the DTFSeeds game scope and must remain tracked until either shipped or explicitly retired:

1. **Strain Match** — educational memory/matching game. Match terms with families, terpene profiles, cultivation symptoms, breeding/seed concepts, or tool uses.
2. **Grow Room Bingo / Bongwater Bingo** — event/community bingo using recurring grower and sesh moments.
3. **Lost in the Terps** — themed word-search missions such as Gas Station Sesh, Grow Room Panic, and Terp Jungle.
4. **Spin the Strain** — wheel-driven strain picker, trivia/challenge selector, giveaway picker, or event reward game.
5. **Mystery Strain** — yes/no strain-trait deduction game with optional wild-card modifiers.
6. **High Lines** — interactive cannabis coloring/activity experience with trippy grow rooms, fantasy gardens, hidden objects, prompts, and creative activities.
7. **Grow Room Defense** — defend plants from pests/pathogens using IPM tools and correct counterplay.
8. **Harvest Hustle** — time-management harvest/trim arcade game.
9. **Pheno Draft** — roguelike genetics deck-builder centered on selection and breeding decisions.
10. **Trichome Trials** — judge/scorecard game using Structure, Resin, Terps, Yield, Color, Documentation, and Problem Solving.

## Release rule

A game is only promoted to the public playable count after it has:

- a canonical source location;
- deterministic rules/data validation where applicable;
- a self-hosted visitor-facing route;
- keyboard/mobile-safe interaction appropriate to the game;
- truthful metadata and release status;
- packaging/deployment registration;
- production route verification after deployment.
