# Master Design Rules for Every Page

## Required visual style

Clean educational infographic.  
Simple beginner publication style.  
Not cartoon overload.  
Not cluttered.  
Not fake textbook.  
Not “stoner poster.”  
Not random AI art.

## Layout

Each page should use the same structure:

### Top
Brand/header:

**THC Simple User Guide**

Main page title:

Example:  
**Setup**

### Middle
One clear educational illustration.

### Bottom or side panels
Short blocks:

- **What it means**
- **What to do**
- **Avoid**
- **Simple rule**

Not every page needs tons of words.

## Text amount

Maximum:

- 1 short title
- 3–5 key points
- 1 avoid box
- 1 simple rule

That’s it.

## Reading level

Beginner. Plain language. No advanced science.

Use:

> Keep soil moist, not soaked.

Do not use:

> Maintain proper substrate moisture and root-zone oxygenation.

---

# Master Prompt Formula

Every page prompt should follow this structure:

> Create a clean vertical educational infographic page for a beginner cannabis cultivation guide. Brand header: “THC Simple User Guide.” Page title: “[PAGE TITLE].” Use a simple premium educational layout with large readable text, clean icons, calm green/natural colors, white or cream background, and one central beginner-friendly illustration. Do not overcrowd the page. Do not use tiny text. Do not add extra information. Use only the listed wording. The page should feel like a simple visual instruction sheet for a first-time lawful home grower.

Then add the exact page content.

# Important Production Rule

Do **not** generate final images with too much text baked into the art unless the text is short and large.

The safest workflow is:

1. Build the **exact page script**
2. Build the **visual prompt**
3. Generate or design the page
4. QA the text
5. Fix errors before moving on

The previous approach failed because it jumped straight into image creation without a locked batch prompt set.

# Correct Batch Goal

The first batch should produce **10 matching pages**, not random one-offs.

Same brand.  
Same layout.  
Same reading level.  
Same structure.  
Same visual quality.

That is the standard moving forward.
