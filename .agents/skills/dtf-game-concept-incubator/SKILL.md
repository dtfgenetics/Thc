# DTF Game Concept Incubator

Concept-only games are stored in `data/game-location-registry.json` with no canonical code location.

## Promotion stages

1. concept-only
2. mechanic specification
3. paper/deterministic rules prototype
4. browser vertical slice
5. canonical source assigned
6. Drive project home assigned
7. content/art production
8. release candidate
9. public promotion

Do not create a repository or Drive master merely because a title exists in the concept bank. Create them when implementation begins.

## First design pass

Define:
- player fantasy;
- core decision;
- primary verbs;
- session length;
- win/loss/end condition;
- replay source;
- solo/local/multiplayer mode;
- minimum content;
- accessibility/mobile requirements;
- engine/runtime choice justified by the mechanic.

Before promotion, update the location and dossier registries so future agents know exactly where the new project lives.
