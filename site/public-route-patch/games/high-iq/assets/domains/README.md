# High IQ domain icons

These ten SVGs are the runtime-ready HIQ-001 domain icon set. `manifest.json` is the deterministic category-to-file contract and is validated against `games/high-iq/data/manifest.json` so the browser never guesses filenames from display text.

The Drive source, approved-master, and runtime-export IDs remain in `data/game-asset-batches/HIQ-001.json`. The assets are intentionally quiet, transparent, label-free, and distinguishable by silhouette at small gameplay sizes.
