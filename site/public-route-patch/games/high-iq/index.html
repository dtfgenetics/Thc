High IQ — Test Higher Cognition

High IQ is DTF Genetics' cannabis knowledge challenge, designed around clear questions, believable answer choices, verified best answers, and explanations that teach instead of simply scoring a guess.

Launch High IQ Back to Game Hub

The current playable build is hosted externally on Base44 while the DTF-hosted version is prepared.

How it plays

A four-level cannabis trivia challenge

Easy

Foundational terminology, plant parts, basic environmental concepts, and common cultivation knowledge.

Medium

Applied cultivation reasoning, plant responses, nutrition, water, lighting, and crop-management concepts.

Hard

More technical genetics, physiology, diagnostics, breeding, environmental control, and post-harvest topics.

Expert

Questions that require precise context, stronger scientific understanding, and careful distinction between similar answers.

Knowledge areas

What High IQ covers

Question pools can cover plant biology, photosynthesis, respiration, hormones, roots, water movement, lighting, PPFD, DLI, pH, EC, nutrition, media, irrigation, integrated pest management, harvest, drying, curing, genetics, breeding, history, terminology, and responsible adult-use culture.

Each production question should ask one clear thing, have one best answer, use believable distractors, and include an explanation that teaches why the answer is correct.

Development status

The browser game is playable, but question balance, difficulty calibration, explanations, interface behavior, scoring, and the self-hosted DTF deployment are still being reviewed. A playable development build is not labeled as a final commercial release.
