Prototype rules

A career lasts 18 turns: six Underground, six Medical, and six Legal. Choose one action each turn. The action changes your resources, then one event from the current era resolves. The random stream is seeded, so identical seeds and choices are reproducible.

Legacy score values reputation, knowledge, assets, compliance, brand, operations, genetics, and remaining cash, with a bonus for a balanced career. Economic values are still playtest values—not final print rules.
