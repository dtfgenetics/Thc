How it works

Fast choices, fictional workflow.

Select a batch. Each ticket shows its next arcade station and current game quality.

Match the station. Correct actions cost one game-second and build combo. Wrong stations cost three seconds and quality.

Beat the clock. Finish batches for value bonuses before the 75-second shift ends. The same code reproduces the same queue.

Game boundary: station names are stylized mechanics only. This game does not provide real-world harvest, drying, processing, chemical, equipment-setting, or consumption instructions.
