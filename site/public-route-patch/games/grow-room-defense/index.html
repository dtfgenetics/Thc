Strategy guide

Observe first. Match the response.

Strong: the tool matches the threat’s primary game weakness and can clear fresh pressure before damage.

Supportive: the tool is useful to the broader IPM response but usually leaves pressure behind.

Mismatch: the tool does not address that game pressure. Unresolved threats keep damaging their bench each round.

Education boundary: this game teaches broad IPM concepts only. It does not provide pesticide recipes, mixing rates, application rates, or treatment instructions.
