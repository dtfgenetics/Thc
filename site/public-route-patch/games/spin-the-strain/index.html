How it works

Complete cycles. Reproducible sessions.

1. Pick a mode. Strain Picker, Grow Challenge, and Community Wildcard each use their own 18-entry cycle.

2. Spin. The selected result comes from the deterministic game engine, not animation timing.

3. Share the code. The same mode and code reproduce the same sequence. Every entry appears once before a new cycle begins.
