Release rule

A project moves up only when it earns the route.

Production status should match the real visitor experience.

1 · Complete

The core visitor flow works without placeholder content or dead-end actions.

2 · Verify

Responsive behavior, navigation, public URLs, data and production checks pass.

3 · Promote

The project moves into its proper customer-facing destination and is linked from the site hierarchy.
