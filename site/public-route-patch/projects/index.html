Internal media-processing and posting-package production system. It remains private operations tooling rather than a public anonymous application.

Not counted as released software

A project being source-controlled does not make it production-ready. Ganjumanji, the standalone THC RPG repository, the legacy All-in-One Grow placeholder, and the two Discord music-bot repositories remain tracked as placeholders until executable code exists or their intended functionality is merged into an active project. Preproduction systems above stay clearly labeled until their release gates pass.
