Release gate

Status must match the visitor experience.

Public navigation, deployment records, project status and the live route are validated as one release contract.

1 · Build

The core visitor flow works and the production package exists.

2 · Verify

Source, registry, route identity, responsive behavior and runtime checks pass.

3 · Promote

Only then does the game receive a public Play link and leave the development roadmap.
