Solar clock reference

Optional planning reference only. Enter coordinates and the local UTC offset manually. The calculator estimates standard sunrise/sunset using a civil-sunrise zenith assumption (90.833°); it does not use device location and it does not decide what photoperiod is biologically appropriate.

Enter date, coordinates and UTC offset to calculate a solar reference.
Assumption boundary: UTC offset must match the date you are planning, including daylight-saving time where applicable. Terrain, buildings, atmospheric conditions and local horizon effects are not modeled.

Interpretation

Photoperiod controls timing. PPFD describes instantaneous photon flux. DLI describes integrated daily exposure. Changing one does not automatically preserve the others.
