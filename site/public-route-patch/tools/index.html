Teaching Healthy Cultivation

Practical tools built around observation, records, and evidence.

DTF tools are designed to help growers organize observations, calculate environmental targets, document decisions, and compare possible plant-health causes without pretending a single photo can prove a diagnosis.

How the tools make claims

Measurements, symptoms, images, and records are evidence—not automatic proof of a single cause. Grow Doc currently uses structured evidence and rule-based differential ranking rather than claiming a validated image-classification model. GrowLens calculations and camera-derived estimates should be calibrated and interpreted in context.
