How these tools make claims

Measurements, symptoms, images, and records are evidence—not automatic proof of a single cause. Grow Doc uses structured evidence and differential ranking rather than claiming a single image proves a diagnosis. GrowLens calculations and camera-derived estimates should be calibrated and interpreted in context.
