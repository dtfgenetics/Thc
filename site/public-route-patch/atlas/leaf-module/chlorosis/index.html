Chlorosis

Chlorosis is yellowing from reduced chlorophyll. It is a symptom category, not a diagnosis.

PreviousLeaf ModuleNext: Necrosis

Visual reference slot

Needed asset: Chlorosis Pattern Checklist comparing uniform yellowing, interveinal yellowing, new growth, old growth, and blotchy yellowing.

Field checklist

  • Mark where yellowing began: old, new, top, bottom, whole plant.
  • Describe pattern: uniform, interveinal, marginal, blotchy.
  • Check if progression is fast, slow, stable, or spreading.

Measurements to pair

  • pH, EC, feed history, water source.
  • Root health, irrigation frequency, substrate moisture.
  • Plant stage and recent environmental changes.

Common mistakes

  • Treating normal senescence as deficiency.
  • Adding nutrients without checking pH or roots.
  • Ignoring pest or disease look-alikes.

Grow Doc prompt

Interpret chlorosis by location and pattern first, then compare pH, EC, feed history, root condition, plant stage, pest evidence, and progression.
