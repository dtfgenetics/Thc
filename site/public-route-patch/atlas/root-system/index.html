Core rule

Leaves often show root problems.

Yellowing, curl, necrosis, slow growth, wilt, and deficiency-like symptoms can all arise from root-zone conditions. Check moisture, oxygen, root temperature, pH, EC, and physical root condition before treating a leaf symptom as a simple nutrient shortage.

Measurement context

Read roots with the environment.

Pair visible root condition with substrate moisture or mass trend, irrigation timing, aeration, root-zone temperature, pH, EC, and the response above ground.

Diagnostic principle

A photograph of a leaf does not identify root function. Combine visible symptoms with root-zone measurements, irrigation history, oxygen or aeration context, and direct root inspection before ranking causes. Continue into Observation & Differential Diagnostics when multiple explanations remain plausible.
