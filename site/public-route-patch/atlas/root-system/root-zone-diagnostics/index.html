Root Zone Diagnostics

Diagnosing root zone problems from plant symptoms requires systematic measurement in the right sequence: pH, EC, temperature, oxygen, moisture, then root inspection. Each measurement either confirms or rules out the next step.

← Root RotModule IndexModule Index
Core rule

Diagnose the root zone before treating the canopy.

The majority of foliar symptoms originate in the root zone. A plant showing yellowing, wilting, or slow growth that does not respond to foliar interventions almost certainly has a root zone problem. Check the root zone first — always.

Measure in sequence

pH → EC → temperature → oxygen → root inspection.

Each measurement constrains the next. Starting with root inspection before measuring pH, EC, and temperature misses the most common causes and risks contaminating the root system.

Diagnostic sequence

Measure runoff pH

Irrigate with 20–30% extra volume. Collect runoff. Test pH immediately. Drift more than 0.5 from target affects multiple nutrients simultaneously.

Measure runoff EC

Compare runoff to input EC. Higher runoff = salt accumulation. Lower runoff may indicate excessive dilution or poor buffering.

Root zone temperature

Insert thermometer at mid-depth. Target 18–24°C. Above 26°C enables pythium; below 18°C slows enzyme-driven uptake.

Assess dryback

Weigh the container. Compare to known field capacity. Determine whether in the correct dryback range for the plant's stage.

Oxygen assessment

Hydro: measure dissolved oxygen directly. Substrate: assess drainage speed — slow drainage indicates compaction or oversaturation.

Root inspection

Only after measuring above — carefully remove plant, inspect root colour, texture, and smell. Confirm or rule out active root rot before treatment.
