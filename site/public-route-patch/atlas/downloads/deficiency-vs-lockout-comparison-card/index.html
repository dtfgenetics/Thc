Deficiency vs Lockout Comparison Card

← All Field Cards

Diagnosing Deficiency vs Toxicity · Teaching Healthy Cultivation

Core rule

Most apparent deficiencies are actually lockout — not absence.

The nutrient is in the substrate. The pH is preventing absorption. Adding more of a locked-out nutrient at the wrong pH changes nothing. Fix the pH first and observe for 5–7 days before adding any element.

Response test

True deficiency responds to adding the element. Lockout does not.

If pH correction alone resolves symptoms within 5–7 days, it was lockout. If symptoms continue after correct pH for a week, check whether the element is actually in the feed at sufficient concentration.

Correct sequence

Correct pH only

Adjust root zone pH to the middle of the target range. Do not add any nutrient yet.

Wait 3–5 days

Observe whether symptoms are stabilising or continuing to spread. New growth is the reference point.

Evaluate response

If improving → lockout confirmed. If unchanged after 7 days at correct pH → check element in feed.

Supplement if needed

Only add the specific element after ruling out lockout. Never adjust pH and add nutrients simultaneously.
