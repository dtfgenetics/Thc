Core rule

Irrigate by container weight — not schedule or visual inspection.

Plant water demand varies with VPD, light intensity, growth stage, and temperature. Container weight at a consistent measuring time is the only reliable indicator of actual dryback.

Dryback delivers oxygen

Controlled drying is the primary mechanism for root zone aeration.

As substrate dries, air re-enters pore space previously filled with water. This oxygen delivery to roots prevents the anaerobic conditions that enable pythium while simultaneously driving calcium transport through transpiration.

Dryback Lab Tool

Container weight protocol

Set field capacity

Irrigate until runoff. Weigh immediately after drainage stops. Record as 100% reference weight.

Set dry reference

Weigh the empty container + dry substrate. This is the 0% reference point.

Calculate target

Target weight = dry + (FC − dry) × (1 − dryback%). 20% dryback = 80% of water capacity remaining.

Irrigate at target

When container reaches target weight, irrigate. Return to FC in one shot or spaced smaller shots.
