Root Zone Problem Map · THC Living Plant Atlas

Core rule

Diagnose the root zone before treating the canopy.

Most foliar symptoms originate in the root zone. A plant showing yellowing, wilting, or slow growth that does not respond to foliar interventions almost certainly has a root zone problem. Check the root zone first — always.

Measure in sequence

pH → EC → temperature → oxygen → root inspection.

Each measurement either confirms or rules out the next step. Starting with root inspection before measuring pH and EC misses the most common causes and risks contaminating the root system.

Response guides

Root rot confirmed

Immediate sequence.

  1. Improve drainage and reduce irrigation immediately
  2. Reduce root zone temperature below 22°C
  3. Improve aeration (airstone in hydro; allow dryback in substrate)
  4. Remove and isolate heavily infected plants
  5. Avoid H₂O₂ — kills beneficial microbes that suppress pythium
  6. Consider Trichoderma after environment is corrected
Salt accumulation confirmed

Flush protocol.

  1. Irrigate with 2–3× container volume at correct pH
  2. Collect and measure runoff EC at the end
  3. Target: runoff EC within 0.5 of input water EC
  4. Allow 20–30% dryback before resuming nutrients
  5. Resume at 50–75% of previous EC, build back over 2–3 feeds
