Safety boundary

This tool does not calculate CO₂ injection rates. CO₂ enrichment can create an asphyxiation hazard. Use appropriate detection, alarms, ventilation, codes and qualified system design.

Published fan ratings can differ from delivered airflow after filters, ducting and static pressure. Use measured or properly corrected airflow for real-room decisions.
