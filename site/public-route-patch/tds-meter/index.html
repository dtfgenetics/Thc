EC in this converter is mS/cm (numerically equivalent to dS/m).

Record the context

Save the meter scale, solution temperature, pH, water source, nutrient recipe, and whether the reading is input, reservoir, runoff, or root-zone extract. Comparing ppm values without knowing the scale can create large errors.
